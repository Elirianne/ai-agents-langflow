# ai-agents-langflow

**Homework 2**: Example of an LLM Agentic workflow with database and tools, designed in LangFlow, used for chat completion

This repo provides a 2-container docker-compose stack:

- **`mongodb`** - a MongoDB database (`perf_metrics`) pre-seeded with a
  fictional application's performance-test metrics, stored as [time-series
  collections](https://www.mongodb.com/docs/manual/core/timeseries-collections/).
- **`langflow`** - the [LangFlow](https://www.langflow.org/) no-code agent
  builder, used to design the actual Agent.

## Dataset

Database `perf_metrics` has one time-series collection generated by
[mongodb/generate_seed_data.py](mongodb/generate_seed_data.py) (30 days of
data) and imported automatically on first container start:

- **`api_performance_metrics`** - one document per day for the `/api/orders`
  endpoint: total requests, OK/NOK counts, error rate %, avg/min/max response
  time, and p50/p90/p95/p99 latency.

A handful of random "incident days" have elevated latency/error rate, so the
agent has interesting regressions and trends to find.

> [!NOTE]  
> To regenerate the sample data (e.g. with different date ranges or hosts),
> edit and re-run `mongodb/generate_seed_data.py`, then recreate the `mongodb`
> container with:
> `docker compose down mongodb -v`,
> `docker compose up -d mongodb`
> so the init scripts run again.

## Setup

1. Copy `.env.example` to `.env` and fill in your Hugging Face token
   (`HF_TOKEN`, from https://huggingface.co/settings/tokens) and `MongoDB`
   credentials.
2. Generate fresh seed data (dates are relative to "today", regenerate before new first start):
   ```powershell
   python mongodb/generate_seed_data.py
   ```
3. Start the stack:
   ```powershell
   docker compose up -d
   ```
4. Open LangFlow at http://localhost:7860 (auto-login is enabled) and import
   [langflow/Perf_Analyzer_Agent.json](langflow/Perf_Analyzer_Agent.json) as
   a new flow.
5. Open the **Language Model** component on the Agent and setup **Model providers**:
   - Select `OpenAI Compatible`
   - **Base URL**: `https://router.huggingface.co/v1`
   - **API Key**: place your `HF_TOKEN` (LangFlow stores it separately from the workflow)
   - Click **Save**
   - **Model**: search and toggle `google/gemma-4-31B-it`
6. Switch to **Playground** (top-right corner)
7. Test with questions like:

   - "Analyze last 7 days of API performance?"
   - "How much did the error rate for API regress between the last two weeks?"

> [!TIP]  
> LangFlow's Agent component has built-in conversational memory, so
> you can ask follow-up questions without repeating context.


## TODO: MCP instead of a Custom Component

Instead of a hand-written Python tool, MongoDB publishes an official [MCP
server](https://github.com/mongodb-js/mongodb-mcp-server) (`mongodb-mcp-server`
on npm) exposing generic `find`/`aggregate`/`count`/etc. tools that LangFlow's
built-in "MCP Tools" component can call directly. It's more "industry
standard" but requires installing Node.js in a custom LangFlow image and
configuring it in stdio mode with `MDB_MCP_CONNECTION_STRING`. Worth trying
once the custom `langflow/components` are working.
